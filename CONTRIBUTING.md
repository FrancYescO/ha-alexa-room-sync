# Contributing

Bug reports and pull requests are welcome.

Before opening an issue, run `alexa_room_sync.preview` and remove all account
identifiers from the response. Never attach a HAR file, cookie, Amazon email,
OAuth token, endpoint ID, or Home Assistant storage file.

For code changes:

1. Keep matching conservative and deterministic.
2. Add or update planner tests.
3. Run Python compilation and the test suite.
4. Update `CHANGELOG.md` for user-visible behavior.
