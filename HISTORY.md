# Reconstructed history

Development initially took place outside Git. The repository history was
reconstructed on 2026-07-26 from preserved ZIP release artifacts.

The file contents of the following release commits come from their respective
archives:

- 0.1.0
- 0.1.1
- 0.2.2
- 0.3.0
- 0.4.0
- 0.5.0
- 0.5.1
- 0.6.0
- 0.7.0
- 0.8.2

Archive modification times were used as approximate commit dates. Generated
files such as `.DS_Store`, `__pycache__`, and `.pyc` files were intentionally
excluded. Versions for which no complete artifact was preserved were not
invented as separate commits.

Tags identify the reconstructed release snapshots. They should not be treated
as cryptographic proof of the original development chronology.
